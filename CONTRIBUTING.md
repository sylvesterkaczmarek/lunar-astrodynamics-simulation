# Contributing

## Repository workflow

This repository uses `main` as the canonical working branch.

- Commit completed changes directly to `main`.
- Do not leave temporary feature branches in the repository.
- Do not include assistant, vendor, model, or coding-tool branding in source code, file or directory names, branch names, comments, documentation, examples, generated artefacts, test fixtures, or user-facing output.
- Keep names technical and specific to the lunar astrodynamics functionality being implemented.
- Keep validation provenance scientific: cite the actual software, numerical method, mission archive, kernel, gravity model, terrain product, or published source used for the result.

These rules apply to both human-authored and tool-assisted contributions.
